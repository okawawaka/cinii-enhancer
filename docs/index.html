Problem & Solution

学術文献調査における2つの無駄を削減

CiNii Researchの日常的な利用で発生する、書式整形の手間と表示の乱れを解消します。

これまでの課題

手動での書誌整形と、判読困難なタグ表示

  • - 引用文献リストを作成する際、タイトル、著者名、巻号、ページ番号を手作業で整形・並び替える必要があった。
  • - 論文抄録（アブストラクト）の中に <jats:p> や <jats:italic> 等の生タグが漏れ出し、文章として読みにくかった。
本ツールの解決策

ワンクリック引用コピーと、完全自動のテキスト整形

  • + タイトル横のボタンから、BibTeX・SIST02・APA・カスタム形式をクリップボードへ直接取得可能。
  • + XML/HTMLタグを自動パースし、段落・斜体・添字として整形表示。原文表示への切り替えも可能。
Core Features

研究・執筆活動に最適化された機能設計

CiNiiの公式UIに溶け込む、端正で信頼性の高いツールセットです。

01 / CITATION EXPORT

ワンクリック引用コピー

検索一覧および論文詳細画面のタイトル横にアクションボタンを配置。設定した優先フォーマットを1クリックでコピーできます。ダイアログから全形式の一括確認も可能です。

SIST02 BibTeX APA 7th RIS MLA
02 / TEXT CLEANER

クリーンテキスト整形

J-STAGEや機関リポジトリ由来の文献で発生する、エスケープされたJATS XMLタグやHTML実体参照（&lt;p&gt;等）を自動サニタイズ。自然な段落と斜体で整形表示します。

DOMParser JATS XML対応 原文切り替え
03 / BULK EXPORT

検索結果の一括コピー

検索画面の標準書き出しバー（TSV / BibTeX / RIS等）の隣にコピーボタンを追加。新規ウィンドウを開くことなく、選択した複数文献の書誌データを直接クリップボードへ格納します。

一括TSV 一括BibTeX バックグラウンド取得
04 / ITEM TYPE ADAPTATION

文献種別の自動判別

図書（単行本）、学位論文（博士論文）、雑誌論文の構造差を自動検知。図書では出版地や出版社名、学位論文では授与大学名を出力し、BibTeXも @book / @phdthesis へ適切に分岐します。

※ 図書の {place}（出版地）補完機能は一部の主要出版社のみの限定対応となっており、未対応の出版社も多く存在します。
図書対応 学位論文対応 BibTeX種別自動化
05 / CUSTOM TEMPLATES

自由なカスタム構文

所属学会や執筆規程に合わせた独自フォーマットを定義可能。{title}, {author}, {authors}, {journal}, {year}, {doi}, {url}, {publisher}, {place} などの変数を自由に組み合わせ、リアルタイムプレビューで確認できます。

※ {place} 変数の自動補完は一部の主要出版社のみ対応しています。
変数置換 種別別テンプレート ライブプレビュー
06 / PRIVACY & SECURITY

完全ローカル・通信不要

外部サーバーへの通信は一切行いません。権限は設定保存（storage）とクリップボード書き込み（clipboardWrite）のみに最小化。機密性の高い研究環境でも安心して利用できます。

外部通信ゼロ 最小権限 Manifest V3
How It Works

わずか3ステップで導入完了

余計な初期設定や外部アカウントの作成は不要です。

01

拡張機能をブラウザに追加

GitHubから本拡張機能をダウンロードし、Chromium系ブラウザ（Chrome, Edge, Brave等）の拡張機能管理画面から読み込みます。

02

CiNii Researchにアクセス

通常通り CiNii Research（cir.nii.ac.jp）を開くだけで、タイトル横に引用ボタンと設定ボタンが自動配置されます。

03

ワンクリックで引用を取得

文献のタイトル横にあるコピーボタンを押すだけで、整形済みの引用テキストが即座にクリップボードへコピーされます。
