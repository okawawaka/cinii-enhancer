# CiNii Research Enhancer (CiNii 拡張機能)

CiNii Research（国立情報学研究所）の論文検索・詳細閲覧を効率化するためのブラウザ拡張機能（Chromium系 / Manifest V3準拠）です。  
絵文字を使用せず、CiNii 本来のサイトデザインに調和する学術的で洗練されたインターフェースを採用しています。

---

## 主な機能

### 1. タイトル横の「クイック直接コピー」＆「引用」ボタン
論文詳細画面および検索結果カードのタイトル右横に、2つの引用アクションボタンをインライン配置：
- **クイック直接コピーボタン（例: `[コピー] BibTeX`）**:
  設定画面で選んだ優先フォーマット（BibTeX / SIST02 / APA / RIS / Markdown 等）を、モーダルを開かず**1クリックで即座にクリップボードへコピー**。論文執筆や文献整理の作業効率を極限まで高めます。
- **引用モーダルボタン（`[引用] 引用`）**:
  クリックすると画面中央にダイアログが開き、全フォーマットのプレビュー確認や他のスタイルへの切り替え・個別コピーが可能です。

対応フォーマット：
- **BibTeX** (`@article`, `@book`, `@phdthesis` 等。LaTeX / Typst にそのまま貼り付け可能)
- **SIST02** (科学技術情報流通技術基準 - 日本の学会・学術論文で標準的な和文引用様式)
- **APA (第7版)** (言語学、心理学、人文・社会科学で汎用的な国際標準スタイル)
- **RIS** (EndNote / Mendeley / Zotero 等の文献管理ソフト用標準データ形式)
- **Markdown (URLリンク付き)** (Obsidian / Notion 等の研究・文献ノート作成に最適)
- **MLA (第9版)**
- **Chicago (第17版 著者-日付形式)**

CiNii Research の Highwire Press メタタグ（`citation_*`）、JSON-LD、DOI情報を精密に解析し、正確な著者名、雑誌名、巻号、ページ数、出版年、DOI、URLを抽出します。

### 2. 詳細画面「書き出し」セクションのワンクリック直接コピー
CiNii 詳細画面にある「書き出し」セクションの「BibTeXで表示」「TSVで表示」「RISで表示」「RefWorksに書き出し」「EndNoteに書き出し」などの各項目のすぐ右隣に、CiNii の外観に馴染む**「コピー」ボタン**を自動設置。  
ファイルのダウンロードや新規タブの遷移を待つことなく、ブラウザ上で該当データをワンクリックで直接クリップボードにコピーできます。

### 3. ノイズのない検索結果画面（引用専用化）
- 検索結果カードのタイトル右横には、CiNii標準のリンクと重複する緑の大きなボタン（機関リポジトリ/J-STAGE）を排除し、**引用関連ボタンのみ**をすっきりと配置。
- 「研究者」や「研究課題」などの引用対象外項目にはボタンが表示されないため、画面の一覧性と視認性を最大限に保ちます。

### 4. 抄録・説明セクションのHTMLタグ自動整形
- **詳細画面でのタグ整形 & 原文切替**:
  エスケープされたタグ（`&lt;p&gt;`）や JATS XML タグ（`<jats:p>` 等）を自然な段落・太字・添字へ整形。左余白（インデント）を確保し、「説明」セクション以外のメタデータを巻き込まない厳密なスコープ制限を実装しています。右上の「原文を表示 / 整形表示に戻す」ボタンでいつでも安全に切り替え可能です。
- **検索結果スニペットのインライン整形**:
  要約抜粋文に含まれる不要タグを除去し、キーワード強調や添字を維持したままスムーズに流し読みできます。

### 5. CiNii ヘッダー設定（歯車マーク）とカスタム引用テンプレート
CiNii 画面上部ヘッダー（ナビゲーション領域）に、サイトデザインに調和した**設定ボタン（歯車アイコン）**が自動的に追加されます。このボタンをクリックすると、ページ内で直接詳細な設定ダイアログが開きます：
- **カスタム引用テンプレートの作成・編集**:
  標準の引用形式に加え、ご自身が執筆する学会誌・紀要の指定様式やノートアプリの記法に合わせた独自テンプレートを自由に入力可能。
  - 使用可能なプレースホルダー：`{title}`, `{authors}`, `{firstAuthor}`, `{year}`, `{journal}`, `{volume}`, `{issue}`, `{pages}`, `{firstPage}`, `{lastPage}`, `{doi}`, `{url}`, `{publisher}`
  - 項目が空の場合でも余分な括弧や「pp.」が残らない自動クリーンアップ処理を搭載。
  - **プリセット読み込み**: 「和文論文 (一般)」「Markdown文献メモ」「英文論文調」のワンクリック挿入ボタン。
  - **リアルタイムプレビュー**: 入力したテンプレートが実際の書誌情報でどう整形されるかをその場でリアルタイム確認。
- **ワンクリックコピー形式の選択**:
  カスタム形式や BibTeX、SIST02 などを選ぶと、タイトル横のボタンラベルが即座に連動（例: `[コピー] カスタム`）し、1クリックで独自形式をクリップボードにコピーできます。

### 6. 設定画面（ブラウザ拡張機能ポップアップ）
ブラウザ右上の拡張機能アイコンからも同様の各種カスタマイズが可能です：
- **Unpaywall 照会用メールアドレスの設定**: 学術API利用規約に沿った適切なアクセス元指定が可能。
- **機能別の個別オン/オフ**: 検索結果引用ボタン、PDF直行ボタン、抄録HTML整形、詳細画面ツールバーの表示切り替え。
- **優先引用フォーマットの指定**: よく使うスタイル（カスタム形式を含む）をあらかじめ指定。

## インストール手順 (Chrome / Edge / Brave 等)

本拡張機能はビルド不要（Vanilla JS + CSS）で動作するため、ソースコードフォルダを直接読み込むだけで利用できます。

1. 本リポジトリをクローンまたはダウンロードします。
   ```bash
   git clone https://github.com/okawawaka/cinii-enhancer.git
   ```
2. お使いの Chromium 系ブラウザ（Google Chrome, Microsoft Edge, Brave, Vivaldi 等）を開きます。
3. アドレスバーに以下を入力して拡張機能管理ページを開きます：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
4. 画面右上の **「デベロッパーモード」** をオンにします。
5. 画面左上の **「パッケージ化されていない拡張機能を読み込む」**（または「展開して読み込み」）ボタンをクリックします。
6. クローンした `cinii-enhancer` フォルダを選択します。
7. [CiNii Research (https://cir.nii.ac.jp/)](https://cir.nii.ac.jp/) を開くと、拡張機能が自動的に有効になります。

## デザイン方針
- **絵文字不使用**: 論文執筆や研究作業の集中を妨げないよう、Unicode絵文字は一切使用していません。
- **学術機関に調和するデザイン**: 現代的なSaaSやAIツールに見られる過度な角丸やブラー（すりガラス効果）、青み系ダークカラーを排除。CiNii Research のオフィシャルなブランドカラー（ネイビーブルー `#004098`）と落ち着いた階調（墨黒 `#333333`、オーセンティックなグレー枠線、2pxシャープ角丸）を徹底し、元来のCiNii画面に自然に溶け込む学術的UIを提供します。
- **軽量・高速**: 外部ライブラリへの依存がなく、CiNii の軽量な動作を損ないません。

---

## プライバシー & セキュリティ

- 本拡張機能はユーザーの閲覧履歴や個人情報を外部サーバーへ送信しません。
- DOI によるオープンアクセス照会は、世界中の学術機関で利用されている Unpaywall の公開 API（`https://api.unpaywall.org/`）とのみ通信します。
