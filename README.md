# CiNii Research Enhancer

CiNii Research（国立情報学研究所）における引用情報の取得、書誌データコピー、および抄録表示の整形を行うブラウザ拡張機能（Chromium系 / Manifest V3準拠）です。

---

## 主な機能

### 1. タイトル横の引用コピーボタン
論文詳細画面および検索結果一覧の各タイトル横に、引用用のアクションボタンを配置します。

- **ワンクリック直接コピーボタン**: 設定された優先フォーマットをクリップボードへ直接コピーします。
- **引用ボタン**: ダイアログを開き、全フォーマットのプレビュー確認や個別コピーを行います。

対応フォーマット:
- BibTeX (`@article`, `@book`, `@phdthesis`)
- SIST02 (科学技術情報流通技術基準)
- APA (第7版)
- RIS (EndNote / Mendeley / Zotero 等)
- Markdown (URLリンク付き)
- MLA (第9版)
- Chicago (著者-日付形式)
- カスタム形式 (独自テンプレート)

### 2. 文献種別ごとの引用フォーマット自動切り替え
文献の種別（論文、図書、学位論文）を自動判別し、適切な書誌項目を出力します。

- **図書（単行本）**: 誌名や巻号に代わり、書名（『』）、出版地、および出版社を出力します。BibTeX では `@book`（`address` フィールド含む）を生成します。
- **学位論文**: 論文題目および授与大学名を出力します。BibTeX では `@phdthesis` を生成します。
- **論文（雑誌・紀要）**: 標題（「」）、誌名（『』）、巻号、ページ範囲を出力します。BibTeX では `@article` を生成します。

### 3. カスタム引用テンプレート
任意のフォーマットを定義できます。設定画面のタブから、文献種別ごとに異なるテンプレートを指定可能です。

- **利用可能な変数**: `{title}`, `{authors}`, `{firstAuthor}`, `{year}`, `{journal}`, `{volume}`, `{issue}`, `{pages}`, `{firstPage}`, `{lastPage}`, `{doi}`, `{url}`, `{publisher}`, `{place}`, `{isbn}`
- **自動使い分け**: 有効時、文献種別に応じて対応するテンプレート（論文用/図書用/学位論文用）が自動的に適用されます。
- **リアルタイムプレビュー**: 編集中のテンプレートの出力結果を各文献種別のサンプルデータで確認できます。

### 4. 書誌書き出し・一括引用の直接コピー
- **詳細画面**: 「書き出し」セクション（BibTeX、TSV、RIS、RefWorks、EndNote）の各項目の右横に「コピー」ボタンを追加します。ダウンロードやタブ遷移を行わずに該当データを直接クリップボードへ取得できます。
- **検索結果画面**: 「新しいウィンドウで開く」プルダウンや書き出し実行ボタンの横に「コピー」ボタンを追加します。チェックボックスで選択した複数文献のデータ（TSV、BibTeX、RIS等）を、新規ウィンドウを開くことなく直接クリップボードへ一括取得できます。

### 5. 抄録・検索結果のHTMLタグ整形
エスケープされたHTMLタグや JATS XML タグ（`<p>`, `<jats:p>` 等）が含まれる抄録や検索結果抜粋を段落・太字・添字として整形表示します。詳細画面では「原文を表示 / 整形表示に戻す」ボタンで切り替えが可能です。

### 6. 設定インターフェース
- **CiNii ヘッダー設定ボタン**: ヘッダー右上に歯車アイコン（設定ボタン）を追加し、ページ内で直接設定ダイアログを開いて編集できます。
- **拡張機能ポップアップ**: ブラウザのツールバーアイコンから、機能の有効/無効の切り替えや優先フォーマットの選択が行えます。

## インストール手順

1. 本リポジトリをダウンロードまたはクローンします。
   ```bash
   git clone https://github.com/okawawaka/cinii-enhancer.git
   ```
2. Chromium系ブラウザ（Google Chrome, Microsoft Edge, Brave, Vivaldi 等）で拡張機能管理ページを開きます。
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. 画面右上の「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、クローンしたフォルダを選択します。
5. [CiNii Research](https://cir.nii.ac.jp/) を開くと自動的に機能が有効になります。

## 設定項目

| 項目 | 説明 | 既定値 |
| :--- | :--- | :--- |
| クイックコピー優先フォーマット | ワンクリックコピー時に使用する引用形式 | BibTeX |
| 文献種別ごとのテンプレート使い分け | 論文・図書・学位論文で別個のカスタムテンプレートを適用する機能 | 有効 |
| 詳細画面の引用ツールバー | 詳細画面のタイトル横に引用ボタンを表示 | 有効 |
| 検索結果の引用ボタン | 検索結果一覧のタイトル横に引用ボタンを表示 | 有効 |
| HTMLタグの自動整形 | 抄録および検索結果のタグを整形表示 | 有効 |

## 動作環境と権限

- **対応ブラウザ**: Google Chrome, Microsoft Edge, Brave, Vivaldi 等の Chromium 系ブラウザ
- **使用権限**:
  - `storage`: ユーザー設定（優先フォーマット、カスタムテンプレート等）の保存と同期に使用します。
  - `clipboardWrite`: 引用テキストや書誌データをクリップボードへ直接コピーするために使用します。
  - `https://cir.nii.ac.jp/*`: CiNii Research のウェブサイト上でのみ動作し、それ以外のドメインには一切アクセスしません。

---

## プライバシー

本拡張機能は閲覧履歴や個人情報を外部サーバーへ送信しません。外部通信を行わず、ブラウザ内のみで処理を完結します。
