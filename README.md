# CiNii Research Enhancer (CiNii 拡張機能)

CiNii Research（国立情報学研究所）の論文検索・詳細閲覧を効率化するためのブラウザ拡張機能（Chromium系 / Manifest V3準拠）です。  
絵文字を使用せず、CiNii 本来のサイトデザインに調和する学術的で洗練されたインターフェースを採用しています。

---

## 主な機能

### 1. ワンクリック引用フォーマット生成・コピー
論文詳細画面および検索結果カードから、クリックひとつで各主要スタイルの引用テキストをクリップボードへコピーできます。

- **BibTeX** (`@article`, `@book`, `@phdthesis` 等。LaTeX / Typst にそのまま貼り付け可能)
- **SIST02** (科学技術情報流通技術基準 - 日本の学会・学術論文で標準的な和文引用様式)
- **APA (第7版)** (言語学、心理学、人文・社会科学で汎用的な国際標準スタイル)
- **Markdown (URLリンク付き)** (Obsidian / Notion 等の研究・文献ノート作成に最適)
- **MLA (第9版)**
- **Chicago (第17版 著者-日付形式)**

CiNii Research の Highwire Press メタタグ（`citation_*`）、JSON-LD、DOI情報を精密に解析し、正確な著者名、雑誌名、巻号、ページ数、出版年、DOI、URLを抽出します。

### 2. フルテキスト PDF への素早い直接アクセス & 事前検知
- **学術オープンアクセス (OA) の自動検出**:
  CiNii ページ内のリンク（J-STAGE、機関リポジトリ、NDL等）に加え、論文の DOI をもとに **Unpaywall API** をバックグラウンドで照会。機関リポジトリや出版社の無料公開オープンアクセス PDF を自動検知します。
- **直行ボタン**:
  詳細ページおよび検索結果一覧に「PDFを閲覧 (オープンアクセス / J-STAGE)」ボタンを設置し、無駄なページ遷移なしにワンクリックで本文を開くことができます。

### 3. 検索結果からのクイック引用 & PDF直接アクセス
- **専用ツールバーの配置**:
  各検索結果カードの直下に、CiNii のデザインと調和する専用のアクションバーを配置。どの論文に対する操作なのかが直感的に分かります。
- **一覧からのクイック引用**:
  検索結果のカードそれぞれに「引用」ボタンを配置。個別詳細ページを開かずとも、画面中央に立ち上がるモーダルから直接 BibTeX や SIST02 をコピーできます。
- **本文・PDF ありバッジ & 直行ボタン**:
  J-STAGE やオープンアクセス等の本文リンクが存在する文献にのみ、高視認性の直行ボタンを表示します。

### 4. 抄録・検索結果のHTMLタグ自動スマート整形
- **検索結果スニペットのインライン整形（案A）**:
  検索結果一覧のタイトルや要約抜粋文に含まれる不要なタグ（`&lt;p&gt;`, `<jats:p>`, `<sec>`, `<font>` 等）を自動で除去・正規化。検索キーワードの強調（太字）や添字（`<sup>`, `<sub>`）を維持したまま、一覧性を崩さずストレスなく流し読みできます。
- **論文詳細画面でのスマート整形 & 原文切替（案3）**:
  詳細画面の長文抄録において、エスケープされたタグや JATS XML タグを自然な段落・太字・添字に変換。抄録枠右上の「原文を表示 / 整形表示に戻す」ボタンで、いつでも生データと即座に切り替え可能です。

### 5. 設定画面（ポップアップ）
ブラウザ右上の拡張機能アイコンをクリックすると、以下のカスタマイズが可能です：
- **Unpaywall 照会用メールアドレスの設定**: 学術API利用規約に沿った適切なアクセス元指定が可能。
- **機能別の個別オン/オフ**: 検索結果引用ボタン、PDF直行ボタン、抄録HTML整形、詳細画面ツールバーの表示切り替え。
- **優先引用フォーマットの指定**: よく使うスタイルをあらかじめ指定。

## インストール手順 (Chrome / Edge / Brave 等)

本拡張機能はビルド不要（Vanilla JS + CSS）で動作するため、ソースコードフォルダを直接読み込むだけで利用できます。

1. 本リポジトリをクローンまたはダウンロードします。
   ```bash
   git clone https://github.com/okawawaka/cinii-enhancer.git
   ```
2. お使いの Chromium 系ブラウザ（Google Chrome, Microsoft Edge, Brave, Vivaldi 等）を開きます。
3. アドレスバーに以下を入力して拡張機能管理ページを開きます：
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
4. 画面右上の **「デベロッパーモード」** をオンにします。
5. 画面左上の **「パッケージ化されていない拡張機能を読み込む」**（または「展開して読み込み」）ボタンをクリックします。
6. クローンした `cinii-enhancer` フォルダを選択します。
7. [CiNii Research (https://cir.nii.ac.jp/)](https://cir.nii.ac.jp/) を開くと、拡張機能が自動的に有効になります。

## デザイン方針

- **絵文字不使用**: 論文執筆や研究作業の集中を妨げないよう、Unicode絵文字は一切使用していません。
- **学術的デザイン**: CiNii のブランドカラー（ネイビーブルー `#004098`）と調和する幾何学的ベクターアイコン（SVG）と高視認性フォント設計。
- **軽量・高速**: 外部ライブラリへの依存がなく、CiNii の軽量な動作を損ないません。

---

## プライバシー & セキュリティ

- 本拡張機能はユーザーの閲覧履歴や個人情報を外部サーバーへ送信しません。
- DOI によるオープンアクセス照会は、世界中の学術機関で利用されている Unpaywall の公開 API（`https://api.unpaywall.org/`）とのみ通信します。
